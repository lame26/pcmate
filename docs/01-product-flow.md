# 제품 플로우 설계

## 서비스 개요

PC 견적 빌드업 웹앱은 사용자의 현재 PC, 사용 목적, 게임, 작업 환경, 모니터 조건, 보유 카드 정보를 바탕으로 적정 사양과 부품 후보를 단계적으로 제안한다.

핵심 결과물은 다음 세 가지다.

- 현재 조건 기준의 사양 판독
- 부품별 절약형/추천형/상급형 후보
- 카드 혜택가를 반영한 최종 견적표

## MVP 사용자 플로우

1. 홈에서 새 견적 시작
2. 빌드 모드 선택
3. 보유 카드 선택
4. 현재 PC 사양 입력 또는 PowerShell 결과 붙여넣기
5. 게임 선택과 목표 옵션 입력
6. 작업/멀티태스킹 조건 선택
7. 모니터/VR/주변기기 조건 선택
8. 예산과 물리적 선호도 입력
9. 사양 판독 결과 확인
10. 가격 수집 또는 가격 데이터 보강
11. 단계별 부품 후보 선택
12. 최종 견적 확인
13. 텍스트 복사 또는 이미지 저장

## 빌드 모드

MVP의 기본 모드는 전체 새 PC 견적이다.

일부 업그레이드는 다음 범위까지만 제공한다.

- 기존 부품 재사용 여부 입력
- 기존 SSD, 케이스, 파워 재사용 의사 저장
- 재사용 선택 시 호환성 경고 표시
- 실제 추천 흐름은 전체 견적 우선

## 화면 구성

### 홈

목적:
- 새 견적 시작
- 기존 localStorage 견적 불러오기
- 다나와 텍스트 가격 분석 바로가기
- 현재 PC 사양 가져오기 바로가기

주요 컴포넌트:
- `StartBuildButton`
- `ResumeBuildCard`
- `QuickParsePanel`

### 카드 선택

목적:
- 사용자가 보유한 카드사와 멤버십을 선택한다.

MVP 범위:
- 카드사명 체크박스
- 멤버십 체크박스는 저장만 하고 가격 계산에는 제한적으로 사용
- 카드 세부 상품명, 전월 실적, 할인 한도는 계산하지 않음

### 현재 사양 입력

입력 방식:
- 수동 입력
- PowerShell JSON 붙여넣기
- PowerShell 일반 텍스트 붙여넣기

결과:
- `CurrentPcSpec`로 정규화
- 파싱 실패 필드는 사용자가 수동 보정

### 게임 선택

기능:
- 30개 이상 게임 목록
- 검색
- 플레이 빈도
- 목표 옵션
- 미출시/예상 게임 배지
- 비주류 게임 권장사양 붙여넣기

판정 원칙:
- 평균이 아니라 가장 높은 요구치와 주력 게임을 우선한다.
- 경쟁 게임은 목표 주사율을 더 강하게 반영한다.
- VR 게임은 GPU와 안정성 가중치를 높인다.

### 작업/멀티태스킹

기능:
- 브라우저 탭 수
- 게임 중 동시 실행 앱
- 개발/작업 앱
- OBS/방송/로컬 AI 항목

결과:
- RAM 권장 용량
- CPU 멀티코어 필요도
- GPU VRAM 필요도
- NVIDIA 선호 가중치

### 모니터/주변기기

기능:
- 해상도
- 주사율
- 모니터 수
- VR 여부
- 캡처보드 여부

결과:
- GPU 목표 티어
- VRAM 권장치
- 파워 여유도

### 예산/선호도

예산:
- 선택 입력
- 총 예산만 MVP에 포함
- 부품별 예산 배분은 내부 추천 로직에서 계산

선호도:
- 색상
- 공랭/수랭
- RGB
- 케이스 크기
- 소음
- NVIDIA/Radeon 선호
- 기존 부품 재사용

### 사양 판독 결과

표시:
- 현재 사양 요약
- 용도 요약
- CPU/GPU/RAM/PSU 필요도
- 병목 가능성
- 과투자 가능성
- 업그레이드 우선순위
- 추천 기준 티어

CTA:
- 가격 데이터 보강하기
- 바로 부품 추천 보기

### 가격 수집

입력:
- 다나와 텍스트 붙여넣기
- 다나와 URL 또는 pcode 입력
- 수동 가격 입력

표시:
- 가격 스냅샷 목록
- 파싱 경고
- 크롤링 갱신 시각
- 가격 신뢰도

### 단계별 빌더

순서:
1. CPU
2. 쿨러
3. 메인보드
4. RAM
5. VGA
6. SSD
7. 파워
8. 케이스

각 단계:
- 절약형/추천형/상급형 후보 3개 기본 표시
- 가격, 혜택가, 적용 카드, 쇼핑몰 표시
- 추천 점수와 이유 표시
- 호환성 경고 표시
- 선택 후 다음 단계 이동

### 최종 견적

표시:
- 부품별 최종 선택
- 일반 최저가
- 내 카드 혜택가
- 적용 카드
- 쇼핑몰
- 배송비
- 할인액
- 총 일반가
- 총 혜택가
- 총 절감액
- 카드별 결제 요약
- 주의사항

출력:
- 텍스트 복사
- 이미지 저장

## 반응형 기준

데스크톱:
- 좌측 단계 진행
- 중앙 후보
- 우측 견적 요약

모바일:
- 상단 진행 표시
- 후보 카드 단일 컬럼
- 견적 요약은 접힘 패널
- 최종 견적표는 가로 스크롤 대신 항목별 카드형 표시
